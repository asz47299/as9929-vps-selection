## 9929 到底是什么线路？

AS9929 是中国联通的 CUII 精品承载网，地位大致相当于联通版的 CN2 GIA。它和普通联通 163 骨干网的核心区别是节点少、负载轻，晚高峰不容易堵，所以回国方向的延迟和丢包控制明显更好。三家的对应关系可以这样记：电信有 CN2 GIA，联通有 AS9929，移动有 CMIN2。

选的时候按自己的宽带运营商对号入座：

- **联通用户**：9929 是亲儿子线路，回程走 AS9929 延迟压得最低，这是搜这个关键词的主力人群。
- **电信用户**：优先 CN2 GIA，9929 对电信的意义有限，因为去程一般不走这条网。
- **移动用户**：首选 CMIN2；不过不少 9929 机房会做「9929+CMIN2 双优化」，移动用户也能沾光。

两个常见的坑提前说。第一，同样是 9929，不同商家接的上游差别很大，稳定性和晚高峰表现不能只看线路名头。第二，9929 解决的是回程拥堵问题，它不管 IP 属性——如果你的用途是 TikTok 运营、电商养号这类对 IP 信誉敏感的事，还要另外看机器给的是原生 IP 还是住宅双 ISP。
